技术选型：Win32原生 + SQLite，单个exe，无需安装任何运行时。

运行方式：常驻系统托盘，Alt+C 呼出关闭窗口，关闭=最小化到托盘。

界面：顶部搜索框 + 降序卡片列表 + 底部状态栏，淡蓝色配色。

卡片功能：置顶、删除、双击复制回剪贴板。

存储：SQLite 存于 %APPDATA%，自动清理30天前未置顶记录。

开机自启：托盘菜单里可选勾选。
